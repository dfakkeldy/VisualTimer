The iPhone run exited 0: 228 unit tests and 16 UI test executions passed,
zero failures. This covers all normal iOS PR-gate test classes plus seven
capture cases. `xcresulttool` reports 243 unique cases; the launch case runs
twice with different configurations. The machine-readable
[receipt](validation-v1.1/iphone-summary.json) preserves that distinction.

Observed through XCUITest actions and native screenshots:

- Quick timer start, pause, frozen paused value, reset, completion and ready state.

confirm that warning's effect on the selected release build. No configuration
change or functional fix is claimed for either warning.
