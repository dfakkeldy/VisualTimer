October 24, 2026 · Project update

The browser timer is live.

Try Turn Timer on the web with six starter templates, editable sequences, local history, and portable template files. Install it on your Home Screen or desktop to return to it easily.

The Apple app now includes history sync, widgets, and an Apple Watch companion that is still in testing. That work reached the release branch in the October 17 promotion.

The iPhone app is in public beta. Join the beta on TestFlight to try it before the App Store release.
